# Hissa Qo'shish Qo'llanmasi

TechSeller AI loyihasiga hissa qo'shganingiz uchun tashakkur! 🎉

## 🚀 Ishga Tushirish

1. **Repository'ni Fork qiling**
   ```bash
   # GitHub'da "Fork" tugmasini bosing
   ```

2. **Lokal kompyuteringizga klonlang**
   ```bash
   git clone https://github.com/YOUR_USERNAME/techseller-ai.git
   cd techseller-ai
   ```

3. **Dependencies o'rnating**
   ```bash
   npm install
   ```

4. **Branch yarating**
   ```bash
   git checkout -b feature/your-feature-name
   # yoki
   git checkout -b fix/your-bug-fix
   ```

5. **Development server ishga tushiring**
   ```bash
   npm run dev
   ```

## 📝 Kod Yozish Qoidalari

### TypeScript
- Har doim type annotation'lar qo'shing
- `any` tipidan qoching
- Interface'lar va type'lar alohida fayllarda

### React
- Functional components ishlatish
- Hooks to'g'ri ishlatish (useEffect, useMemo, useCallback)
- Component'lar kichik va fokuslangan bo'lsin

### CSS
- CSS variables ishlatish
- Tailwind utility class'lar afzal
- Responsive dizayn (mobile-first)

### Naming Conventions
- Components: PascalCase (`MyComponent.tsx`)
- Functions: camelCase (`myFunction`)
- Constants: UPPER_SNAKE_CASE (`MY_CONSTANT`)
- CSS classes: kebab-case (`my-class-name`)

## 📤 Pull Request Jarayoni

1. **Commit qiling**
   ```bash
   git add .
   git commit -m "feat: add new feature"
   # yoki
   git commit -m "fix: resolve bug"
   ```

2. **Push qiling**
   ```bash
   git push origin feature/your-feature-name
   ```

3. **Pull Request yarating**
   - GitHub'da repository'ga o'ting
   - "New Pull Request" tugmasini bosing
   - Branch'ingizni tanlang
   - PR description'ni to'ldiring

4. **Review kuting**
   - Maintainer'lar PR'ni ko'rib chiqadi
   - O'zgarishlar so'rashi mumkin
   - Approve qilingandan keyin merge qilinadi

## 🎯 Commit Message Qoidalari

### Format
```
<type>: <description>

[optional body]
```

### Types
- `feat`: Yangi xususiyat
- `fix`: Bug fix
- `docs`: Hujjatlar o'zgarishi
- `style`: Kod formatlash (funksional o'zgarishsiz)
- `refactor`: Kodni qayta tuzish
- `test`: Test qo'shish/o'zgartirish
- `chore`: Build, CI, dependencies

### Misollar
```bash
feat: add AI chat functionality
fix: resolve QR code countdown issue
docs: update README with new features
style: format code with Prettier
refactor: simplify component structure
test: add unit tests for utils
chore: update dependencies
```

## 🎨 Dizayn Qoidalari

- Apple HIG tamoyillariga rioya qiling
- Whitespace'ni to'g'ri ishlatish (80px macro, 4-24px micro)
- Animation'lar 150-400ms orasida
- Color psychology'ga amal qiling
- Accessibility'ni unutmang (4.5:1 contrast)
